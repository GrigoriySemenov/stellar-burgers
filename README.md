# Stellar Burgers

Приложение космической бургерной на React, TypeScript и Redux Toolkit. Основано на стартовом наборе проекта.

## Локальный запуск

Требуется Node.js 22.12+ или 24 LTS.

```bash
npm ci
npm start
```

Откройте http://localhost:4000. Файл `.env` уже содержит адрес учебного API:

```env
BURGER_API_URL=https://norma.education-services.ru/api
```

Если `.env` отсутствует, скопируйте `.env.example` в `.env`. Для загрузки ингредиентов, авторизации и заказов требуется интернет.

## Возможности

- Конструктор с выбором булки, добавлением, удалением и перестановкой начинок, счётчиками и подсчётом стоимости.
- Детали ингредиентов и заказов в модальных окнах и на отдельных страницах по прямым ссылкам.
- Регистрация, вход, выход, восстановление пароля и обновление данных профиля.
- Защита личного кабинета и истории заказов, возврат на запрошенную страницу после входа.
- Оформление заказа с очисткой конструктора после успешного ответа сервера.
- Лента и личная история с автоматическим обновлением каждые 5 секунд, а также сразу после оформления заказа.
- Обновление токена доступа и обработка ошибок запросов.

## Проверки

```bash
npm run check
npm run typecheck
npm test -- --runInBand
npm run build
```

Тесты проверяют Redux, операции конструктора, обработку запросов, создание заказа, авторизацию, восстановление пароля, обновление токенов и очистку личных данных при выходе.

```bash
npm run storybook
```

Компоненты доступны в Storybook на http://localhost:6006.
