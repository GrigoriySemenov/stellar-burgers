# Stellar Burgers

Приложение космической бургерной на React, TypeScript и Redux Toolkit. Основано на стартовом наборе проекта.

## Локальный запуск

Требуется Node.js 22.12+ или 24 LTS.

```bash
npm ci
npm start
```

Откройте http://localhost:4000. Файл `.env` уже содержит адрес учебного API:

```env
BURGER_API_URL=https://norma.education-services.ru/api
```

Если `.env` отсутствует, скопируйте `.env.example` в `.env`. Для загрузки ингредиентов, авторизации и заказов требуется интернет.

## Возможности

- Конструктор с выбором булки, добавлением, удалением и перестановкой начинок, счётчиками и подсчётом стоимости.
- Детали ингредиентов и заказов в модальных окнах и на отдельных страницах по прямым ссылкам.
- Регистрация, вход, выход, восстановление пароля и обновление данных профиля.
- Защита личного кабинета и истории заказов, возврат на запрошенную страницу после входа.
- Оформление заказа с очисткой конструктора после успешного ответа сервера.
- Лента и личная история с автоматическим обновлением каждые 5 секунд, а также сразу после оформления заказа.
- Обновление токена доступа и обработка ошибок запросов.

## Проверки

```bash
npm run check
npm run typecheck
npm test -- --runInBand
npm run build
```

Юнит-тесты Jest находятся рядом с хранилищем и API, а тесты редьюсеров — в `src/services/slices/__tests__`. Они проверяют начальное состояние, неизвестные экшены, добавление, удаление и перестановку ингредиентов, обработку асинхронных запросов, авторизацию и оформление заказа.

### Покрытие Jest

```bash
npm run test:coverage
```

Результат выводится в терминал, HTML-отчёт сохраняется в `coverage/index.html`. В отчёте учитываются слайсы и модуль API. Для `ingredients.ts` и `constructor.ts` задан порог покрытия 100% по строкам, выражениям, функциям и ветвлениям.

### Интеграционные тесты Playwright

При первом запуске установите Chromium:

```bash
npx playwright install chromium
```

Запуск тестов:

```bash
npm run e2e
```

Playwright самостоятельно запускает приложение на `http://127.0.0.1:4173` в режиме `test`. Порт должен быть свободен. Предварительно запускать `npm start` не требуется.

В `tests/constructor.pl.tsx` проверяются добавление и замена булок, начинки и соусы, счётчики и стоимость, данные ингредиента в модальном окне, закрытие крестиком, оверлеем и Escape. Для заказа проверяются состав запроса, токен, номер заказа, очистка конструктора, закрытие модального окна и сохранение бургера при ошибке сервера.

Ответы API воспроизводятся через `page.routeFromHAR` из `tests/hars`: ингредиенты, пользователь, создание заказа, лента и история заказов, а также ошибка оформления. Тесты используют фиктивные токены и отдельный адрес API `https://stellar-burgers.test/api`. Остальные внешние запросы блокируются. После установки зависимостей и браузера доступ к учебному серверу для тестов не требуется.

Открыть HTML-отчёт или интерактивный режим:

```bash
npm run e2e:report
npm run e2e:ui
```

Отчёты покрытия, результаты Playwright и диагностические файлы исключены из Git.
